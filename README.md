# Forge

A reproducible developer workstation environment.

## In Short...

Forge transforms a fresh Arch Linux installation into a personalized development platform.

## The Forge Philosophy

Forge believes the best development environment is one you eventually stop noticing.

The terminal should disappear.

The tools should disappear.

The operating system should disappear.

Only the act of creating should remain.

Forge exists to reduce the distance between an idea and working software.

## Components

- Arch Linux
- KDE Plasma
- Zsh
- Starship
- Nerd Fonts
- Modern CLI tooling
- Git/GitHub integration

## Guiding Principles

### What should Forge optimize for?
Forge exists because development environments should invite creation, not create friction. Every unnecessary distraction, every piece of unnecessary complexity, and every obstacle between an idea and working code steals momentum. Forge is built to remove that friction.

Peace. Serenity. Euphoria. It may sound silly, but developing on other platforms can at times be overwhelming. Sometimes, the nature of the platform one uses for development can push them away from development all together.

I don't want this to happen. To myself. Or anyone else interested in picking up development as a hobby, passtime, passion project, or potential career.

Forge optimizes for efficiency, minimalism, and those moments that you just don't get using other environments.

The result should be peace.

The result should be clarity.

The result should be flow.

### What should Forge intentionally _not_ do?
Forge will never force anything or anyone to be something they don't want to be. Forge will not install unnecessary bloat on a new machine. Forge will never claim to be the end all be all of development platforms.

Forge _will_ provide the tools that enable developers to be creative. Forge _will_ bring peace and satisfaction to development. Forge _will_ be a uniquely different experience from mainstream products.

### What does "done" look like?
Forge may _never_ be done. Forge may be an ongoing, forever improving, constantly evolving platform with various versions catered to different needs, wants, and goals.

The work is never done.

### If someone cloned Forge five years from now, what experience should they have?
They should feel a sense of internal peace. They should feel a sense of calm. They should feel empowered to create beyond what they thought imaginable.

They should Forge.
